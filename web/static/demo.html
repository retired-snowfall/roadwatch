Live demo

Upload a road-camera video. The same pipeline that we submit runs on it and returns every detected event as a time segment, an annotated playback and the causal accident-risk curve.

1 · Choose a video

Accepted: .mp4 (also .mov, .avi, .mkv, .webm) up to 200 MB and 3 minutes. Two minutes is plenty. The file stays on the demo server for 3 hours and is then deleted.

2 · Processing

Waiting for a video.

The demo server runs on CPU with the nano detector at 5 analysed frames per second, so processing takes roughly one to two times the video length. The submitted solution runs the medium detector on a GPU.

3 · Results

Results appear here: timeline, annotated playback, risk curve and the events table. Want to look first? See the results on the sample videos.
