WIUT Hackathon 2026 · Computer Vision track

Every traffic event on one fixed camera, as a time segment — and an alarm before the crash.

roadwatch watches a CCTV view of a road, reports collisions, near misses, red-light and wrong-way driving, jaywalking, congestion and nine other event classes with start and end times, and raises a causal risk score seconds before an accident happens. It runs offline on one GPU well inside three times real time.

How it works

See

A COCO-pretrained YOLO11 finds people, bicycles, motorcycles, cars, buses, trucks, animals and traffic lights; a ByteTrack-style tracker links them into trajectories.

Understand the road

From thousands of trajectories in the sample videos the system learns, without labels, where the carriageway is, which way each lane flows and where queues stop.

Decide

One rule per event class reads trajectories against that road model and writes segments that follow the annotation conventions. A separate causal chain turns time-to-collision into risk.
